Добрый день!

Хочу кратко рассказать, как устроен сервис agent-clicker и из чего он состоит.


ЧТО ДЕЛАЕТ СЕРВИС

Сервис автоматически выполняет действия на сайтах так, как это делал бы живой человек. Вы передаёте ссылку и описание задачи — сервис сам разбирается, что и в каком порядке нужно сделать, открывает сайт и выполняет действия.

При этом каждый запуск выглядит как отдельный пользователь: своё устройство, свой браузер, свой IP-адрес, своя манера работы с сайтом.


КАК ЭТО РАБОТАЕТ ИЗНУТРИ

Задачи хранятся в базе данных PostgreSQL. Как только приходит время выполнения, сервис берёт задачу в работу, подбирает уникальный профиль пользователя и запускает браузер.

Для управления браузером используется Playwright — современный инструмент, который умеет работать с Chromium, Firefox и WebKit. Поверх него подключены скрипты, которые скрывают признаки автоматизации, чтобы браузер выглядел как обычный.

Описание задачи обрабатывается языковой моделью (LLM), которая составляет пошаговый план действий на сайте. Этот план затем выполняется в браузере.

Все действия имитируют поведение живого человека: мышь движется плавными кривыми, а не по прямой; текст вводится с нерегулярными паузами и редкими опечатками; скролл идёт короткими «толчками»; между шагами — случайные задержки, как будто человек читает страницу или думает. Время на сайте — от 30 секунд до нескольких минут.


УНИКАЛЬНОСТЬ КАЖДОГО ЗАПУСКА

Для каждой задачи генерируется новый профиль: user-agent, разрешение экрана, язык, часовой пояс, характеристики видеокарты и аудио — всё подобрано согласованно под конкретное «устройство». Используется новый IP-адрес через резидентные прокси. После выполнения задачи профиль удаляется.


НАДЁЖНОСТЬ

Если что-то пошло не так, задача автоматически повторяется (до 3 раз с нарастающим интервалом). Если сервис «завис» — отдельный watchdog-процесс обнаруживает это и перезапускает задачу. При сбое сохраняются скриншоты для диагностики.


СТЕК КОРОТКО

Python 3.11, asyncio, Playwright, PostgreSQL, языковая модель через OpenAI-совместимый API, резидентные прокси, Docker.
